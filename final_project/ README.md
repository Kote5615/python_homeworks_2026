# GigaVibeMiptCode

позволяет разговаривать с нейронкой. здесь я подключила и использовала дипсик апи но кажется yaml нельзя коммитить

в проекте реализованы:

- почанковая загрузка
- отказоустойчивость
- промт
- все переменные окружения берутся из yaml
- ограничение контекста для сообщений (токены то платные! :>)

чтобы запустить приложение нужно запустить файл giga_bot.py
python giga_bot.py из папки final_project

код разбит на модули

Команды

- Выход из приложения \q
- Очистка истории /reset
- Обработка файла по частям /file_chunk
- Прикрепление файлов @::filepath::
